# Credits

## Dragon Island

A cozy stealth adventure game for browsers, designed by two creative young designers and built with open-source technologies.

### Design
- Game concept and features designed by Human 1 and Human 2

### Development
- Built with [Phaser 3](https://phaser.io/) - Open source HTML5 game framework (MIT License)
- TypeScript compilation and bundling via [Vite](https://vitejs.dev/) (MIT License)
- Testing with [Vitest](https://vitest.dev/) (MIT License)
- Browser testing with [Playwright](https://playwright.dev/) (Apache 2.0 License)

### Audio
- All sound effects generated procedurally using the Web Audio API
- No external audio assets used

### Art
- All graphics generated procedurally using Phaser's Graphics API
- No external image assets used
- Color palette inspired by cozy adventure games

### Fonts
- System fonts used (platform-native)

### Inspiration
- Game design inspired by Sneaky Sasquatch (Apple Arcade)
- Cozy game aesthetic from titles like Stardew Valley and A Short Hike
